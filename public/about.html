About String Time

String Time is a free, open-source guitar practice tracker that runs entirely in your browser. It is built around a simple idea: the hardest part of practising guitar on your own is not playing — it is knowing what to practise next and seeing whether you are actually getting better.

What it does

  • Chord library — a built-in library of common guitar chords plus a custom chord builder (click the fretboard or type x 3 2 0 1 0-style notation). Each chord carries its own practice time, BPM trend, and accuracy.
  • Progression builder — sequence chords into progressions with your own time signature and bars-per-chord. Drag to reorder.
  • Metronome with tempo ramp — Web Audio metronome with a 4-bar playhead. Routine items can carry a per-item tempo ramp (as a percentage) that drives BPM from a start speed up to a target over the item's duration, so you train deliberate speed increases instead of staying on the same BPM forever.
  • Routines — ordered lists of practice items (chord or progression, BPM, time signature, duration, ramp %). Start one item or run the whole routine back-to-back.
  • Today's plan — three chords and a progression picked each day from your own history: the chord with the lowest recent accuracy, the one you haven't touched in the longest, any BPM plateau you've hit, and a progression that uses them.
  • History and stats — GitHub-style 365-day practice heatmap, days/weeks/months chart, current and longest streaks, average minutes per day, most active hour, per-chord totals, and a fretboard density map.
  • Private by default — all data lives in your browser's IndexedDB. Nothing is sent anywhere. Export and import JSON backups to move between browsers.

Pain points it tries to solve

“I don't know what to practise today.”

Most guitar practice apps hand you a long tutorial track and leave planning to you. Today's plan does the opposite: it reads your logged sessions and picks a short, targeted set — the chord that's been slipping, the one you've been avoiding, and a BPM you've plateaued at. If you have ten minutes, you have a list. That's spaced repetition applied to guitar chords and progressions, in the spirit of Anki but for your fingers.

“I can't tell if I'm actually getting better.”

Every chord carries a BPM trend sparkline, a total time counter, and an accuracy signal. The dashboard heatmap shows you a year at a glance. If a chord is stuck at the same BPM for weeks you'll see it — and the daily plan will put a ramp on it.

“I keep breaking my practice streak.”

String Time shows your current streak and longest streak, a 14-day minutes chart, and a session-list that reaches back as far as you've played. The daily plan is short on purpose: a smaller target you'll actually meet is worth more than a long one you skip.

“I don't want to sign up for yet another app.”

There is no account. There is no server that holds your practice history. Your chords, progressions, routines and session log live in your browser's local database. Export to JSON if you want a copy; import on another device if you're moving. If you clear site data, you clear your history — just like a notebook.

“I'm self-taught and have no teacher to tell me what to work on.”

The daily plan is the closest thing to a teacher looking over your shoulder that a static page can offer. It won't fix your technique, but it will remind you that you haven't drilled F in two weeks and that your G-major-at-120 has plateaued.

How to use it

  1. Open stringtime.app in any modern browser.
  2. The chord library is seeded on first load.
  3. Click a chord in the Library to pop the floating player — pick a BPM, pick a time signature, hit Start.
  4. Build a routine in Routines: add items, give each one a BPM, duration and optional tempo ramp percent, and press Start routine.
  5. Check back the next day — Today's plan rebuilds from the latest sessions.

Technology

String Time is a static web page. No build step, no server, no analytics. It uses the Web Audio API for the metronome (with a lookahead scheduler so the beat stays locked to the audio clock) and a Karplus-Strong plucked string synth with a modeled guitar body for the chord audio. Practice data is stored in IndexedDB. The source is on GitHub.
